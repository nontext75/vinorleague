# vinorleague

새 디자인 콘셉트의 스튜디오 포트폴리오 초안.

```sh
npm install
npm run dev
```

로컬 주소: http://127.0.0.1:3000

Next.js App Router, Tailwind CSS v4, DaisyUI v5, Motion, Outfit.

기획과 콘텐츠 확인 항목: [docs/site-plan.md](docs/site-plan.md).
문의는 메일 앱 연동 방식이며 서버에 저장하거나 자동으로 전송하지 않습니다.

```sh
npm run build
npm run check
```
