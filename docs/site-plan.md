# vinorleague 리뉴얼 초안

콘텐츠 기준: https://vinuspread.vercel.app/ (2026-09-27 확인)
이미지 보완: https://vinus.co.kr/index.php 의 동일 프로젝트 실제 작업물.

## 방향

사용자 수정 지시: 공유 사이트의 콘텐츠 형태와 메인 흐름을 유지하고, 디자인을 별도로 새롭게 만든다.
메인 기획의 최신 기준은 [main-plan.md](main-plan.md)이다. 아래 페이지 구성과 이번 초안의 범위는
현재 구현 상태의 기록이며, 수정될 메인 기획과 구분한다.

기존 초안의 스티커형 첫 화면, 임의로 만든 슬로건, 단순화한 소개 구성은 채택하지 않는다.
가칭 로고는 vinorleague. 디자인 콘셉트는 메인 콘텐츠 구성과 분리하여 검토한다.

## 페이지 구성

| 페이지 | 내용 | 다음 행동 |
|---|---|---|
| 홈 | 소개, 대표 작업 6개, 스튜디오, 서비스 4개, 고객사 로고, 글 3개 | 작업 또는 문의 |
| Work | 기존 프로젝트 8개, 분야별 필터 | 프로젝트 상세 |
| 프로젝트 상세 | 제목, 작업 이미지, 소개, 고객, 분야 | 다음 프로젝트 |
| Studio | 철학, Think/Mind/Behavior, 서비스 | 작업 또는 문의 |
| Stories | 기존 글 10개, 한국어 제목·요약 | 글 상세와 기존 원문 |
| Contact | 작업 분야, 회사/담당자/이메일/연락처, 예산, 프로젝트 설명 | 문의 메일 작성 |

초안은 한국어 설명과 영문 제목을 사용한다. 기존 `/work`, `/studio`, `/news`,
`/contact`와 각 상세 주소를 유지한다. 완전한 한·영 전환은 후속 단계에 둔다.

## 콘텐츠 점검 결과

- 기존 Work는 8개. Aliot과 The Frame도 Web으로 분류되어 있어 초안에서 Branding/Editorial로 재분류했다.
- 기존 프로젝트에 커피·화장품·회의 사진 등 프로젝트와 무관한 임시 사진이 사용되어 있었다.
  실제 원본 사이트에서 제목이 일치하는 8개 작업 썸네일로 교체했다. 현재 480×360이므로 최종 공개 전 고해상도 원본이 필요하다.
- 웅진 캐릭터 상세의 주소는 `mongdang`, 고객 표기는 `Mongdang Studio`, 기간은 2023.08이지만
  원본 사이트의 웅진 작업은 2020.04이다. 초안은 제목을 기준으로 웅진 작업을 표시하며, 검증되지 않은 기간은 노출하지 않는다.
- 기존 Studio의 서비스 설명 일부에 같은 UX 문장이 반복된다. 서비스별 요지를 짧게 다시 정리했다.
- 기존 Download Brochure는 PDF가 아니라 Contact로 이동한다. 실제 PDF 확보 전 다운로드 버튼을 넣지 않는다.
- 기존 소셜 링크는 서비스 메인 주소만 가리킨다. 실제 계정을 확인하기 전 노출하지 않는다.
- 글 10개의 제목·날짜·요약은 기존 공개 콘텐츠를 바탕으로 옮겼다. 디자인 원칙 글은 본문까지 옮기고,
  나머지는 요약과 원문 링크를 제공한다. 전체 본문 이관은 후속 작업이다.
- 연락처는 새로 공유한 사이트의 이메일·전화·주소 기준이다. 상호 확정 시 함께 정리한다.

## 이번 초안의 범위

- 반응형 홈과 내부 페이지, 분야 필터, 모바일 메뉴, 서비스 펼치기, 작업 간 이동.
- 실제 자료를 로컬에 저장하고 WebP로 변환. 출처는 `asset-sources.json`에 기록.
- 문의는 메일 앱을 열어 사용자가 확인 후 전송하는 방식. 별도 서버 접수나 저장은 하지 않는다.
- 관리 화면, 문의 접수 서버, 파일 업로드, 실제 PDF, 모든 글 본문, 한·영 전환은 후속 단계.
- 로컬 미리보기용. 원격 배포는 진행하지 않으며 검색 노출도 비활성화했다.

## 후속 순서

1. 공유 사이트 기준으로 메인 콘텐츠 순서와 내용을 복원한 뒤 디자인 방향 검토.
2. 작업 이미지 고해상도 확보, 상세 정보 오류 수정, 글 전체 이관.
3. 문의 접수와 관리자 기능 연결, 한·영 콘텐츠 완성.
4. 모바일·키보드·접근성·이미지 속도 검증 후 공개.
