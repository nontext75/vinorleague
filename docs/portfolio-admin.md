# 포트폴리오 관리자

관리자 주소는 `/admin`입니다. Sanity Studio에서 프로젝트를 등록·수정하고 공개 여부와 Work 목록 순서를 관리합니다. 게시되지 않은 초안은 사이트에 노출되지 않습니다.

## 처음 한 번 연결하기

1. [Sanity 관리 페이지](https://www.sanity.io/manage)에서 프로젝트를 만들고 Project ID를 확인합니다.
2. 프로젝트 루트의 `.env.local`에 아래 값을 입력합니다. `.env.example`을 참고하세요.

   ```text
   NEXT_PUBLIC_SANITY_PROJECT_ID=프로젝트_ID
   NEXT_PUBLIC_SANITY_DATASET=production
   NEXT_PUBLIC_SITE_URL=https://사이트주소
   ```

3. Sanity 프로젝트의 CORS 설정에 개발 주소 `http://127.0.0.1:3001`을 등록하고, 배포 후에는 사이트 주소도 추가합니다. 관리자 로그인을 위해 자격 증명 허용을 켭니다.
4. 개발 서버를 다시 시작한 뒤 `/admin`에 Sanity 계정으로 로그인합니다.
5. 기존 포트폴리오 8개를 옮길 때는 Sanity 쓰기 토큰을 `.env.local`의 `SANITY_API_TOKEN`에 넣고 `npm run sanity:import-work`를 한 번 실행합니다. 토큰은 `NEXT_PUBLIC_` 접두사를 붙이지 않습니다.

## 프로젝트 등록과 수정

- 목록 대표 이미지, 상세 상단 이미지, 고객사, 분야, 연도, 진행 시기, 정렬 순서를 입력합니다.
- 상세 설명은 섹션 제목과 문단을 나눠 입력하고, 이미지는 순서대로 올립니다. 이미지 초점과 대체 텍스트도 함께 지정합니다.
- 검색 노출 탭에서 검색 결과 제목과 설명을 입력할 수 있습니다. 제목은 비우면 프로젝트명, 설명은 비우면 프로젝트 개요에서 자동으로 가져옵니다.
- `사이트에 공개`를 끄면 데이터를 지우지 않고 사이트에서 숨깁니다. 순서는 숫자가 작을수록 앞에 표시됩니다.
- 저장 뒤 Publish를 누르면 사이트에 공개됩니다. 내용은 최대 1분 안에 Work 목록, 상세 페이지와 홈의 주요 프로젝트에 반영됩니다.

## 데이터와 보안

- 기존 포트폴리오는 최초 연결 전까지 로컬 JSON에서 표시됩니다. CMS에 저장한 프로젝트가 있으면 해당 프로젝트만 덮어쓰고, 나머지 기존 프로젝트는 그대로 유지합니다.
- 이미지 파일은 Sanity에 저장되고 사이트에는 공개된 이미지 주소만 전달됩니다. 게시된 공개 포트폴리오만 비밀 토큰 없이 읽습니다.
- `SANITY_API_TOKEN`은 최초 자료 이관에만 사용하고 `.env.local`에만 보관합니다. 저장소에 올리지 않습니다.
