# vinorleague 메인 콘텐츠 기획

## 기준

- 기준 사이트: https://vinuspread.vercel.app/
- 사용자의 요청: 해당 사이트의 콘텐츠 형태로 메인을 구성하되, 디자인은 다른 콘셉트로 제작.
- 가칭 로고: vinorleague.
- 이 문서는 콘텐츠 종류, 순서, 역할을 정한다. 색상·서체 크기·배치·모션 등 시각 표현은 별도 설계한다.
- 2026-09-27: 메인 콘셉트 초안에 콘텐츠 구성을 반영했다. 대표 6개 순서, 독립 철학 섹션, 4개 서비스 세부 항목, 고객사 28곳, 글 3개 요약, 사업·채용 문의 정보를 적용했다.
- 원본 HTML에 재생 가능한 영상 소스가 없고 실제 회사소개서 PDF도 확인되지 않아 영상 재생/다운로드 버튼은 노출하지 않는다. 실제 계정이 확인되지 않은 소셜 링크와 전체 번역이 필요한 언어 전환도 후속 항목이다.

## 메인의 흐름

무엇을 하는 회사인지 → 어떤 가치를 추구하는지 → 실제로 무엇을 만들었는지 →
어떻게 함께 일하는지 → 누구와 일했는지 → 어떤 생각을 하는지 → 프로젝트 문의.

### 1. 첫 화면 — 브랜드의 약속

기존 `We design sustainable growth`와 첫 아이디어부터 마지막 디테일까지 함께한다는 설명을 사용한다.
단순히 보기 좋은 결과물을 만드는 곳을 넘어 방향 설정, 경험 설계, 지속적인 개선을 함께하는 스튜디오임을 전달한다.

- 핵심 문장, 이를 설명하는 짧은 문단, 대표 비주얼.
- 회사소개서 연결은 기존 사이트의 의도를 유지하되 실제 PDF가 있어야 다운로드로 제공한다.
- 새 가칭에서 의미를 추측해 임의의 브랜드 철학이나 슬로건을 만들지 않는다.

### 2. 스튜디오 소개 — 본질과 아름다움

기존 `We focus on essential value and elevate it with beauty`에 해당하는 독립 섹션.
변화 속에서도 오래가는 가치를 찾고, 디자인으로 아이디어의 가능성을 넓힌다는 소개를 담는다.

- 회사가 중요하게 여기는 가치가 중심.
- 작업 방식과 서비스 목록은 여기에서 섞지 않는다.
- `The Studio`를 통해 스튜디오 상세로 연결.

### 3. Experience — 대표 프로젝트

기존 메인에 선택된 6개 프로젝트와 순서를 기준으로 한다.

1. Woongjin ThinkBig AI Education App Character
2. Shinhan Easy Financial Education Platform UI Design
3. Online Outsourcing Platform Crowd OH!
4. Daekyo Macadamia Website
5. Budongsan114 Mediate BIZsolution
6. Dong-A Publishing OnBook

프로젝트별로 대표 이미지, 분야, 이름, 작업의 성격을 보여준다.
각 상세 페이지와 `Browse all work`로 연결한다. 단순한 로고 모음이 아니라 어떤 작업을 했는지 읽히도록 한다.
프로젝트의 이름과 내용은 새 공유 사이트 기준으로 유지하며, 임시 사진은 일치하는 실제 작업 이미지로 보완한다.

### 4. How we work — 함께 일하는 범위와 방식

기존 `Always there, from first idea to final detail`의 내용을 별도 섹션으로 둔다.
초기 방향부터 출시 이후 개선까지 이어지는 협업을 설명한다.
기존 사이트의 경력 및 AI 활용 설명은 출처 내용으로 정리하고, 실제 공개 문구는 사실 확인 후 확정한다.

| 분야 | 기존 콘텐츠에서 담을 내용 |
|---|---|
| Product Strategy | Discovery, Roadmap, AI Opportunity |
| Experience Design | UX/UI, Web, App |
| Brand Systems | Identity, Visual Direction, Content |
| Launch & Operation | CMS, SEO, Analytics |

`Explore our services`와 `See our work`로 더 자세한 설명과 결과물을 확인할 수 있게 한다.
기존 영상·모션 소개 영역도 이 흐름에서 다루되, 재생 가능한 실제 영상이 있는지 먼저 확인한다.

### 5. Clients — 협업 경험

기존 사이트의 고객사 로고 목록과 협업 소개를 옮긴다.
현재 로컬 초안처럼 임의로 6개만 남기지 않고, 원래 고객사 목록을 기준으로 한다.
메인의 역할은 여러 산업에서 쌓은 협업 경험을 보여주는 것. 확인하지 않은 성과 수치나 추천사는 추가하지 않는다.

### 6. Ideas & Insights — 스튜디오의 관점

기존 메인의 대표 글 3개를 유지한다.

- 브랜드 컬러를 감으로 고르면 안 되는 이유 — 2026.04.20
- 디자인 원칙이 없으면 생기는 일 — 2026.05.22
- 버튼 하나에서 시작하는 UX 라이팅 — 2026.05.01

이미지, 글 분류, 날짜, 제목, 짧은 설명을 포함한다. 이전 초안에서 빠진 설명도 복원한다.
글 상세와 `View all stories`로 연결한다. 기존 메인의 선정 순서는 유지하며, 날짜순 자동 배치는 별도 결정이다.

### 7. Contact — 문의와 회사 정보

기존의 다음 프로젝트를 함께 시작하자는 메시지와 문의 연결을 유지한다.

- 프로젝트 문의.
- 사업 문의 이메일, 전화·팩스.
- 채용 문의 이메일.
- 영업시간.
- 회사 주소.
- 실제 계정으로 확인된 소셜 링크.

연락처는 공유 사이트를 기준으로 한다. 기존 소셜 링크가 플랫폼 첫 화면을 가리키는 상태이므로
실제 계정 확인 없이 그대로 연결하지 않는다.

## 공통 메뉴

원본의 Experience / Studio / Story / Contact 구성을 기준으로 한다.
한·영 전환과 회사소개서 접근 의도도 보존하며, 번역과 실제 파일이 갖춰진 뒤 기능을 활성화한다.

## 이전 초안에서 바꿀 점

- 임의의 `Good things, built together` 중심 구성 대신 원본의 회사 소개 메시지로 돌아간다.
- 대표 작업 앞에 스튜디오 철학 섹션을 독립적으로 배치한다.
- 대표 프로젝트 6개를 원본 선정 목록과 순서로 맞춘다.
- 회사 철학과 일하는 방식을 합치지 않는다.
- 원본의 네 서비스 분야와 세부 항목을 보존한다.
- 고객사 목록, 글 설명, 사업/채용 문의 등 누락된 정보를 복원한다.
- 스티커, 2열 카드, 아코디언 등 이전 초안의 디자인 형식은 기획의 전제로 삼지 않는다.

## 이후 제작 순서

1. 이 구성으로 실제 문구와 자료를 섹션별로 정리한다.
2. 같은 콘텐츠를 사용해 새 디자인 방향을 잡는다.
3. 첫 화면과 바로 이어지는 소개·작업 영역으로 디자인 방향을 먼저 검토한다.
4. 방향이 맞으면 나머지 메인과 내부 페이지에 확장한다.
